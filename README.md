🎨 Responsive Login Page (HTML & CSS Only)

A clean and modern Login Page UI built using only HTML and CSS.
This project uses CSS hover effects, glassmorphism, and responsive design techniques—no JavaScript involved.

✨ Features
✅ Pure HTML & CSS only
🧊 Glassmorphism login card
🎯 Smooth CSS hover effects
📧 Email & 🔑 Password fields
🔁 “Forgot Password?” link
📜 Privacy Policy checkbox
📱 Fully responsive layout
🎨 Soft pastel color theme

🛠️ Technologies Used

HTML5

CSS3

Flexbox

Media Queries

Hover Effects

Responsive Units
